# ВМуткоин Обменник — Fabric 26.2

## Сборка Windows

Требуется **JDK 25**, Fabric 26.2, Fabric API 26.2, мод `vmtrade` (для предмета `vmtrade:vmcoin`) и LuckPerms 5.5 или новее.

Запуск сборки:

    build.bat

или:

    gradlew.bat build

Готовые JAR-файлы создаются в `build/libs/`.

## Установка и размещение обменников на базах стран

Мод регистрирует блок/предмет `vmexchange:exchange`. Он добавлен в творческие вкладки «Функциональные блоки» и «Строительные блоки». Рецепта крафта нет: блок следует выдавать администраторам через творческий инвентарь или команду `/give @s vmexchange:exchange`.

У каждого размещённого блока собственная привязка к группе LuckPerms. Не настроенный обменник закрыт для всех игроков.

1. Администратор ставит блок на базе страны.
2. Наводит прицел на сам блок с расстояния не более 8 блоков.
3. Выполняет `/vmexchange bindgroup europe` (вместо `europe` укажите нужную группу LuckPerms). Например, можно использовать `africa` или `avstralia`, если эти группы существуют на сервере.
4. Команда `/vmexchange groupinfo` показывает текущую привязку блока.
5. Команда `/vmexchange unbindgroup` снимает привязку и снова закрывает обменник для всех.

Для доступа проверяется основная группа игрока и группы, унаследованные через LuckPerms. Если игрок не входит в группу, назначенную конкретному обменнику, он не сможет открыть интерфейс. Сервер повторно проверяет доступ при покупке, так что уже открытое меню не обходится после смены группы. Привязки сохраняются в данных мира, относятся к конкретному измерению и координатам блока и удаляются при обычном разрушении блока игроком.

## Недельный обмен и цены

По умолчанию лимит — 25 ВМуткоинов в неделю. На каждый обмен требуется ровно один набор из четырёх выбранных материалов; одно нажатие выдаёт ровно один `vmtrade:vmcoin`. Материалы и цены управляются конфигурацией `config/vmexchange.json` и командами `/vmexchange`.

Недельный сброс по умолчанию происходит в понедельник в 00:00. Первые три материала выбираются из `standardMaterialIds`, четвёртый — из `specialMaterialIds`. Nether-ресурсы не используются в автоматическом выборе.
